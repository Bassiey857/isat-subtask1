Sub-Task 1: GitHub vs. GitLab Analysis
​1. Three Key Features of GitHub
​GitHub Actions: Allows developers to set up automated workflows that test, build, and deploy code directly inside repositories whenever new changes are uploaded.
​Pull Requests & Code Review: Enables team members to review code changes, leave inline feedback, and approve merges safely before updating the main project.
​GitHub Pages: A free feature that turns a project repository into a live, hosted website directly from GitHub.
​2. Three Key Features of GitLab
​Built-in CI/CD Pipelines: Provides continuous integration and deployment out-of-the-box using simple configuration files (.gitlab-ci.yml) without needing external plugins.
​Complete DevOps Lifecycle Tool: Includes tools for every stage of software development, from project management and coding to security scanning and performance monitoring.
​Issue Boards: Built-in agile boards that help teams organize tasks, track bugs, and manage workflow progress alongside their code.
​3. Licensing Distinction
​GitHub operates primarily as a proprietary software-as-a-service (SaaS) platform owned by Microsoft. While free to use for hosting public and private code, the underlying source code of GitHub itself is closed-source.
​GitLab uses an open-core model. Its Community Edition (CE) is free and open-source (MIT license), allowing developers and organizations to install and run the full platform on their own private servers for complete data control.
​4. Feature Comparison
​Common Features (5 Shared Capabilities):
​Git version control system (VCS) and repository management.
​Pull Requests (GitHub) / Merge Requests (GitLab) for team collaboration.
​Integrated issue trackers and bug reporting tools.
​Web-based code repository viewer with syntax highlighting and file editing.
​User access controls and project permissions.
​Unique to GitHub:
​GitHub Copilot: Deeply integrated AI pair-programmer powered by OpenAI.
​GitHub Marketplace: A large store of third-party actions, apps, and extensions.
​Unique to GitLab:
​Native Self-Hosting: Full-featured, free-to-deploy self-hosted Community Edition (GitLab CE) for infrastructure control.
​Built-in Container Registry: Native image storage for Docker containers within projects.
